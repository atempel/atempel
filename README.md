# About me

Product designer in São Paulo. I've spent 16 years moving between advertising, UX and software, and these days most of my work happens where design, engineering and AI overlap: context engineering, agent workflows, and the methods that make AI tools useful for real work. I also write about design and AI, in English and Portuguese.

## Things I'm building

- **[workspace//kit](https://github.com/atempel/workspace-kit)**: generates structured workspaces for AI projects, with `AGENTS.md` and `CLAUDE.md` layers so agents start with the right context.
- **[Sonic Obsidian](https://github.com/atempel/sonic-obsidian)**: an audio visualizer inspired by the old Winamp visualizations, and the project where my design-to-code process with AI came together.
- **Molde** (working name): open-source tooling to help designers and developers write a proper `DESIGN.md`, so coding agents stop guessing what your design system looks like.
- **Working Illusion**: my blog and YouTube channel about AI experiments, design and code. Coming soon.
- **Mise**: recipes, meal plans, pantry and grocery list as one connected system. I manage it by talking to Claude through an MCP connector, and browse the same data in a mobile app.

## How I like to work

- AI is a tool. I design the context around it more carefully than the prompts.
- I keep some friction on purpose: design and development live in separate sessions, and nothing ships without me testing the build.
- I don't reinvent the wheel: I'm happy to build on what others made. I build my own when I can't find what I need, or when there's an idea I want to explore.
- Simple and repeatable beats impressive and fragile.
